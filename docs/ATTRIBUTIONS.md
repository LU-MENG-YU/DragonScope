# Technical references / provenance

No third-party repository source code is copied into this package.

Public behavior and endpoint contracts were independently implemented after inspecting public websites and public GitHub projects as technical references, including:

- CPBL official website: https://www.cpbl.com.tw/
- CPBL Stats: https://stats.cpbl.com.tw/
- Wei Chuan Dragons official site: https://www.wdragons.com/
- `pochih/cpbl2026`: useful public reference for current CPBL schedule/box request behavior and cloud-IP limitations.
- `lin-junyou/cpbl-savant-py-app`: useful public reference for the CPBL Stats public endpoints and page-data structure.

At packaging time, no LICENSE file was found in the two referenced GitHub repositories above, so their implementation code was not reused.
